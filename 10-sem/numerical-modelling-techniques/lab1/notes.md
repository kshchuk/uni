## 2. Фізична постановка задачі (Лаб. №1)

**Тема:** моделювання стаціонарної ламінарної течії навколо перешкоди заданої форми.

Аналогія з викладачем: течія навколо острова в протоці (напр. Керченська протока й острів Тузла, або острів Борнхольм у морі) — обтікання перешкоди довільного контуру.

Постановка (навчальна, "тренуємось на кішках" — простий приклад із зрозумілим фізичним змістом, щоб опанувати саму обчислювальну технологію):

- Область течії — площина `(x, y)` (плоска задача: уздовж осі `z` картинка не змінюється).
- Течія — **стаціонарна** (характеристики не залежать від часу) і **потенціальна**: існує потенціал `φ`, такий що вектор швидкості `V = (u, v) = grad φ = (∂φ/∂x, ∂φ/∂y)`.
- На нескінченності швидкість виходить на постійний вектор `V∞`, `|V∞| = 1`, `V∞ = (cos α, sin α)`.
- Перешкода задається контуром `Ld` довільної форми (у кожного студента — свій контур/"ієрогліф").

## 3. Математична постановка (п. 7.1.1 посібника)

Оскільки течія потенціальна, `φ` — гармонійна функція, яка задовольняє **рівняння Лапласа** всередині області `D⁺`:

```
Δφ = ∂²φ/∂x² + ∂²φ/∂y² = 0,   r ∈ D⁺           (7.1.1)
```

Крайові умови:

- **Умова непроникнення** на межі перешкоди (нормальна похідна = 0):
  ```
  ∂φ/∂n = 0,   r = rd ∈ Ld            (7.1.2)
  ```
  Еквівалентно: `(V, n)|rd = 0`.
- **Умова збереження циркуляції** — інтеграл по замкненому контуру `C`, що охоплює `Ld`:
  ```
  ∮ (∂φ/∂n) ds = Γ0 = const   по контуру C, що охоплює Ld     (7.1.3)
  ```
- **Умова на нескінченності** (зовнішня задача):
  ```
  lim(r→∞) grad φ = V∞               (7.1.4)
  ```

Це — **зовнішня задача Неймана** для рівняння Лапласа (задається не сама функція, а нормальна похідна на межі).

> Викладач окремо наголосив: умова непроникнення (7.1.2) — це не те саме, що умова нестисливості з рівнянь Нав'є-Стокса/Ейлера; тут вона з'являється саме з постановки як умова обтікання твердої межі.

### Чому область не однозв'язна

Через наявність перешкоди (контур `Ld` "виїдає дірку" з площини) область течії — **двозв'язна**. Порядок зв'язності визначається кількістю розрізів, що з'єднують межу з нескінченно віддаленою точкою, плюс один:

- 0 розрізів → однозв'язна;
- 1 розріз → двозв'язна (наш випадок);
- N розрізів → (N+1)-зв'язна.

Саме через неоднозв'язність потрібна додаткова умова (7.1.3) з контуром `C` і константою `Γ0`, яка виділяє **єдиний** розв'язок (без неї задача Неймана на неоднозв'язній області має розв'язок, визначений з точністю до довільної циркуляції).

## 4. Аналітичний розв'язок у термінах ТФКЗ (теорія функцій комплексної змінної)

Розв'язок шукається як **характеристична функція** — комплексна сума потенціалу `φ` (дійсна частина) і функції течії `ψ` (уявна частина), які пов'язані умовами Коші-Рімана:

```
∂φ/∂x = ∂ψ/∂y,    ∂φ/∂y = -∂ψ/∂x
```

```
Φ(z) = φ(x,y) + iψ(x,y) = zV̄∞ + (1/2πi) ∫_Ld γ(ω) ln(z − ω) dω + Const     (7.1.5)
```

Комплексно спряжена швидкість (похідна від `Φ`):

```
V̄(z) = u(x,y) − iv(x,y) = dΦ/dz = V̄∞ + (1/2πi) ∫_Ld γ(ω)/(z − ω) dω        (7.1.6)
```

- `γ(ω)` — невідома **підінтегральна функція** ("густина" особливостей на контурі); якщо вона відома (разом з геометрією `Ld`), розв'язок `Φ(z)` обчислюється одразу.
- Інтеграл у (7.1.5) — з логарифмічним ядром; у (7.1.6), після диференціювання — з ядром типу **Коші**. Для точки `z`, що лежить на самому контурі `Ld`, такий інтеграл не існує у звичайному сенсі Рімана — лише як **головне значення за Коші**.

Підстановка (7.1.6) у крайові умови (7.1.2)–(7.1.3) дає систему **сингулярних інтегральних рівнянь** відносно `γ` (7.1.11)–(7.1.12). Аналітично її можна розв'язати лише для канонічних контурів (відрізок, дуга кола тощо). Для довільного контуру застосовується **обчислювальний (чисельний) метод**.

## 5. Метод дискретних особливостей (МДО) — дискретизація

Ідея: контур `Ld` розбивається на `M` **граничних елементів** `L1, …, LM`. На кожному елементі замість неперервного розподілу `γ(ω)` розміщується **дискретна особливість** — точкова інтенсивність `Γj` у середній точці елемента `ω0j = x0j + i y0j`.

Параметри дискретизації (п. 7.1.2):

1. **Контур у системі координат** — впорядкований масив точок розташування дискретних особливостей `ω0j = x0j + i y0j`, `j = 1..M`.
2. **Точки колокації** `ωk`, розташовані між сусідніми дискретними особливостями (їх на одну менше — `M−1`):
   ```
   xk = (x0k + x0(k+1)) / 2,   yk = (y0k + y0(k+1)) / 2
   ```
3. **Масив нормалей** у точках колокації `nk = (nxk, nyk)`, обчислюється через координати сусідніх точок особливостей (формули 7.1.2, п. "Масив нормалей").
   - Напрямок обходу контуру: область дослідження `D⁺` (де шукаємо течію) має залишатись **ліворуч** при русі вздовж контуру за зростанням індексу — стандартне правило обходу в теорії сингулярних інтегральних рівнянь.
4. `M` — кількість дискретних особливостей (студент обирає сам, обмежень немає; головне — щоб алгоритм підтримував змінне `M`).
5. `Γ0` — задана циркуляція, що виділяє єдиний розв'язок.
6. `V∞ = (cos α, sin α)`, `|V∞| = 1` — швидкість набігаючого потоку (задається напрямком `α`).

### Дискретизований розв'язок (в дійсних змінних)

```
φ(x,y) = xu∞ + yv∞ − Σ_{j=1}^{M} (Γj/2π) · arctg[(y − y0j)/(x − x0j)]      (7.1.13)/(11)

ψ(x,y) = −yu∞ + xv∞ + Σ_{j=1}^{M} (Γj/2π) · ln√[(x−x0j)² + (y−y0j)²]      (7.1.14)/(12)

V(x,y) = V∞ + Σ_{j=1}^{M} Γj · Vj(x,y,x0j,y0j)                             (7.1.15)/(13)

Vj(x,y,x0j,y0j) = ( (y0j−y)/(2π r²) , (x−x0j)/(2π r²) ),   r² = (x−x0j)²+(y−y0j)²   (7.1.16)/(14)
```

Кутова функція `arctg[(y−y0j)/(x−x0j)]` — це так званий **круговий арктангенс** (потрібно враховувати чверть/знаки, а не просто `atan`), геометрично — кут нахилу прямої з точки `ω0j` на точку `(x,y)`.

### Регуляризація (щоб уникнути ділення на нуль поблизу особливостей)

Коли `(x,y) → (x0j, y0j)`, вирази для `ψ` (логарифм нуля) і `V` (знаменник `→0`, тобто `1/0`) прямують до нескінченності — звідси й назва методу ("дискретні особливості"). Щоб цього уникнути, відстань `r` до кожної особливості обмежують знизу малим параметром `R0j`:

```
R0j = max( rj , √[(x−x0j)² + (y−y0j)²] ),   rj ≈ 0.01     (7.1.18)/(10),(15)
```

`R0j` (параметр регуляризації) підставляється замість `r` у формулах для `ψ` і `V` — тоді функції всюди скінченні, і особливостей на графіках немає.

### Система лінійних алгебраїчних рівнянь (СЛАР)

Підстановка дискретизованого розв'язку в крайові умови (7.1.2)–(7.1.3), записані в точках колокації, дає **систему `M` лінійних алгебраїчних рівнянь відносно `M` невідомих `Γ1, …, ΓM`**:

```
Σ_{j=1}^{M} Γj · (nk, Vj(xk,yk,x0j,y0j)) = −(nk, V∞),   k = 1, …, M−1     (7.1.19)/(20)

Σ_{j=1}^{M} Γj = Γ0                                                      (7.1.20)/(21)
```

- Перших `M−1` рівнянь — з умови непроникнення (7.1.2) у точках колокації (їх рівно на одну менше, ніж невідомих, бо точок колокації `M−1`).
- Останнє, `M`-те рівняння — з умови циркуляції (7.1.3): сума всіх інтенсивностей дорівнює заданій `Γ0`.

Розв'язавши цю СЛАР (звичайний метод розв'язання лінійних систем, напр. Гаусс), отримуємо вектор `(Γ1, …, ΓM)`, а з ним — за формулами (7.1.13)–(7.1.16) — поля `φ`, `ψ`, `V` у будь-якій точці області.

## 7. Що з формул "працює", а що ні (за посібником, для довідки/самоперевірки)

У записі пари ця частина explicite не встигла прозвучати (лекція перервалась на прикладі з пікселями), але в презентації та посібнику є контрольний приклад — **аналітичний розв'язок для циркуляційної течії навколо кругового циліндра** (слайди 11, 14–16 презентації; використовується як еталон для перевірки чисельного (дискретизованого) розв'язку):

```
Φ(z) = V∞(z + a²/z) + (Γ/2πi) ln z
V̄(z) = dΦ/dz = V∞(1 − a²/z²) + Γ/(2πi z)
```

де `a` — радіус циліндра. Для `Γ=0`, `Γ>0`, `Γ<0` виходять три якісно різні картини обтікання (симетрична течія / зі зсувом критичних точок за рахунок циркуляції) — зручний тестовий приклад, на якому можна порівняти дискретизований розв'язок (метод дискретних особливостей, формули 28–29 презентації) з точним аналітичним, перш ніж застосовувати метод до довільного контуру, для якого аналітичного розв'язку немає.

- «Довгий Черніт Раценко» → «Довгий, Троценко, Черній» (автори посібника);
- «Гамельтон(а)» → «Гамільтон(а)» (оператор Гамільтона / набла);
- «Нав'єстокса» → «Нав'є-Стокса», «Ейлєра» → «Ейлера»;
- «ядром типу Каши», «значення Пакаши» → «типу Коші», «значення за Коші» (Cauchy);
- «умови Каширіна» → «умови Коші-Рімана»;
- «система лінійних логібраїчних рівнянь» → «... алгебраїчних рівнянь»;
- «острів Баранхольм» → «острів Борнхольм».

Файли `.srt` і `.json` залишено без змін (сирий вивід ASR з таймкодами) — виправлення внесено лише у `.txt`. Інші можливі дрібні неточності розпізнавання (специфічна математична термінологія, що вимовлялась швидко) могли залишитись невиправленими.
