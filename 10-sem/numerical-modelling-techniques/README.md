## Конспект (lab1/notes.md)

Структурований конспект пояснення лабораторної №1: постановка задачі, аналітичний
розв'язок (ТФКЗ), метод дискретних особливостей, дискретизація, регуляризація, СЛАР
і завдання до лаби — зі звіркою за навчальним посібником та презентацією.

## Покроковий гайд (lab1/guide/guide.pdf)

Як виконати лаб. №1 самостійно, від контуру до графіків, на прикладі варіанту «С» (півколо).
Теорія (постановка, зв'язність, ТФКЗ, сингулярне рівняння, МДО, Б-умова) і 8 кроків: для кожної
формули — виведення «звідки це» з посиланнями на посібник, слайди й хвилини лекції. Контрольний
приклад із числами, тести на пластині та циліндрі, еталонні графіки, типові помилки, структура звіту.
Готової програми гайд не містить — лише алгоритм кожного кроку.

Перезбірка PDF: `pip install typst && cd lab1/guide && python3 -c "import typst; typst.compile('guide.typ', output='guide.pdf')"`
