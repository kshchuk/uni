## Конспект (lab1/notes.md)

Структурований конспект пояснення лабораторної №1: постановка задачі, аналітичний
розв'язок (ТФКЗ), метод дискретних особливостей, дискретизація, регуляризація, СЛАР
і завдання до лаби — зі звіркою за навчальним посібником та презентацією.

## Покроковий гайд (lab1/guide/guide.pdf)

Як виконати лаб. №1 самостійно, від контуру до графіків: дискретизація, колокації й нормалі,
регуляризація, СЛАР, круговий арктангенс і перетворені формули для φ/ψ, побудова 4 графіків,
перевірка на точному розв'язку для пластини, типові помилки, структура звіту. Готової програми
гайд не містить — лише алгоритм кожного кроку та контрольний приклад із числами для самоперевірки.

Перезбірка PDF: `pip install typst && cd lab1/guide && python3 -c "import typst; typst.compile('guide.typ', output='guide.pdf')"`
