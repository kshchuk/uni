## Конспект (lab1/notes.md)

Структурований конспект пояснення лабораторної №1: постановка задачі, аналітичний
розв'язок (ТФКЗ), метод дискретних особливостей, дискретизація, регуляризація, СЛАР
і завдання до лаби — зі звіркою за навчальним посібником та презентацією.

## Покроковий гайд (lab1/guide/guide.pdf)

Як виконати лаб. №1 від контуру до графіків: дискретизація, колокації й нормалі, регуляризація,
СЛАР, круговий арктангенс і перетворені формули для φ/ψ, побудова 4 графіків, перевірка на точному
розв'язку для пластини, типові помилки, структура звіту. Код у гайді підтягується з `mdo_lab1.py`.

Перезбірка:

```
pip install numpy matplotlib typst
cd lab1/guide && python3 make_figures.py && python3 -c "import typst; typst.compile('guide.typ', output='guide.pdf')"
```

## Варіант «С» (lab1/variant-C)

Контур — літера «С» як гладке півколо, відкрите праворуч (діаметр 1; точки особливостей і колокації лежать
на дузі, нормалі — точні нормалі до кола), M = 80, V∞ = (1, 0),
Γ0 ∈ {−1, 0, 1}. `report.pdf` — чернетка звіту: постановка, метод, вхідні дані, 4 графіки для кожного Γ0,
перевірки (непроникнення ~1e-15, ΣΓ = Γ0, збіжність ~1/M), висновки, код. Перезбірка:

```
cd lab1/variant-C && python3 variant_c.py && python3 -c "import typst; typst.compile('report.typ', output='report.pdf', root='..')"
```
