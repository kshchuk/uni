# mdo — метод дискретних особливостей (ТЧМ, лаб. №1 і №2)

Бібліотека з математикою лабораторних робіт курсу «Технології чисельного моделювання»:
стаціонарна течія навколо контуру з циркуляцією Γ0 (лаб. №1) і нестаціонарна відривна течія
з вихровим слідом і доріжкою Кармана (лаб. №2). Навчальний покроковий код лишається в
гайдах лабораторних; тут той самий розрахунок зібрано в повторно використовуваний пакет.

## Встановлення

В іншому проєкті (приватний репозиторій — потрібен доступ до GitHub):

```bash
pip install "git+https://github.com/kshchuk/mdo.git"
# або в requirements.txt:  mdo @ git+https://github.com/kshchuk/mdo.git
```

Для розробки:

```bash
git clone https://github.com/kshchuk/mdo.git && cd mdo
pip install -e ".[test]"
pytest -m "not slow"         # швидкі тести (~3 с)
pytest -m slow               # повне відтворення лаб. №2 (~2 хв)
```

## Приклади

```python
import numpy as np
from mdo import Contour, SteadySolution, Simulation, plot_four, plot_wake

# Лаб. №1: півколо (варіант «С»), M = 80, Γ0 = 1
sol = SteadySolution.solve(Contour.semicircle(80), v_inf=(1, 0), gamma0=1.0)
print(sol.G.sum(), sol.residual())          # Γ0 і нев'язка непроникнення ~1e-16
plot_four(sol, delta=sol.contour.h / 2)     # V, |V|, φ (перетворена формула), ψ

# Лаб. №2: відрив вихорів, доріжка Кармана
sim = Simulation(Contour.semicircle(24)).run(80)
print(sim.summary())                        # середній Cx і число Струхаля
plot_wake(sim, [5, 20, 40, 80]); plot_four(sim)

# Будь-який кут потоку і будь-який контур
a = 1.0
sim = Simulation(Contour.semicircle(24), v_inf=(np.cos(a), np.sin(a))).run(40)
c = Contour.polyline([(0.5, 0.5), (-0.5, 0.5), (-0.5, -0.5)], 31)   # «Г»: відрив з кінців і кута
```

## Що де

| Модуль | Зміст | Формули посібника |
|---|---|---|
| `contour.py` | `Contour`: дуга / півколо / ламана / довільні точки, колокації, нормалі, точки відриву, δ, `keep_out` | §7.1.2, §7.2.2, §7.2.4, с. 133 |
| `kernels.py` | швидкість від вихору з регуляризацією, сума від багатьох вихорів, круговий арктангенс | (7.1.14), (7.1.17)–(7.1.18), (7.2.24)–(7.2.26) |
| `fields.py` | поля V, ψ, φ (пряма й перетворена формули), сітки | (7.1.13′)–(7.1.25′), (6.4.42)–(6.4.43) |
| `steady.py` | лаб. №1: матриця і СЛАР, `SteadySolution` | (7.1.19)–(7.1.20) |
| `unsteady.py` | лаб. №2: `Simulation` — відрив, рух, крок за часом, СЛАР з умовою Кельвіна, сили через імпульс | (7.2.19)–(7.2.20), (7.2.27), (7.2.32), §6.5.1 |
| `plotting.py` | контур, 4 графіки полів, вихровий слід | — |

Примітки:
- крок за часом τ = δ / max|V|, де максимум береться по вільних вихорах (а не по всій області);
- новонароджені вихори зсуваються вже в кроці відриву (i = 1..n+1, формула (39) слайда 10);
- сили Cx, Cy рахуються через гідродинамічний імпульс (Wu, 1981) — у посібнику формули немає;
- тиск (Cp) не реалізовано;
- `Simulation(..., absorb=(центр, радіус))` поглинає вихори в майже замкнених порожнинах
  (передаючи їхню циркуляцію контуру) — потрібно для контурів на кшталт «5».
